# Security Policy

## Supported versions

Only the latest release gets fixes. Please update before reporting.

## Reporting a problem

Please **don't open a public issue** for security problems. Report them privately instead:
[Security → Report a vulnerability](https://github.com/DHIRAJ-J-S/MinimalSF_Launcher/security/advisories/new).

Include what's affected, how to reproduce it, and which version you tested. You should hear back within a week.

## Scope

MinimalSF has no internet permission, so most issues will be about other apps on the phone misusing it, for example:

- Getting around the signature permission that protects the MinimalSF Extended connection
- Reading MinimalSF's data (keywords, todos, hidden apps) from another app
- Launching or hiding apps without the user's action

Problems in the [MinimalSF Extended](https://github.com/DHIRAJ-J-S/MinimalSF_Extended) plugin should be reported on its own repository.
